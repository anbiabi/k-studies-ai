# Official GKS source library

This folder is the local, versioned source library for K-Studies AI.

## Update once per year

1. Open the current **GKS Notice** board on [Study in Korea](https://www.studyinkorea.go.kr/en/plan/gksNotice.do).
2. Replace or add the current undergraduate and graduate guideline files in a new year folder.
3. Update `official-sources.md` with the notice URL, revision date, and attached-file names.
4. Keep older years for comparison, but never treat them as current requirements.

The application uses the concise official extracts in `official-sources.md` as its primary context. The linked NIIED/Study in Korea files remain the final authority for deadlines, country quotas, documents, and university lists.

## Current source set

- `official-sources.md` — maintained source register and offline facts used by the AI.
- `2026/README.md` — 2026 official notices and attachments.
- `2027/README.md` — 2027 official notices and attachments currently published.

Only official sources are listed here: NIIED, Study in Korea, Korean diplomatic missions, and designated universities.
